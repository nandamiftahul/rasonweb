RASON Monitoring — Release v1.1.0

Refactor Release — Modular Architecture & Enhanced Security

Version: v1.1.0 Date: 28 Oct 2025 Developed by: Terrindo

1. Overview

Summary

Rason Monitoring (RasonWeb) adalah platform web terpadu untuk pemantauan, analisis, dan visualisasi data radiosonde BMKG (BUFR/BFR/BFH/BIN). Refactor Release v1.1.0 menandai selesainya fase utama pengembangan sistem dengan arsitektur modular, frontend seragam, serta fitur analitik dan keamanan yang lengkap.

2. Project Objectives

Goal
  • Menstandarkan decoding & QC radiosonde di seluruh stasiun BMKG.
  • Menyediakan analisis otomatis berbasis fisika atmosfer.
  • Menampilkan hasil interaktif melalui dashboard web.
  • Monitoring kualitas data antar-site secara real-time.
  • Menjamin keamanan user & integrasi admin control.

4. Key Features

Highlights
  • Automatic BUFR/BFR/BFH/BIN decoding + SQLite cache.
  • Deep Physics QC (tropopause, freeze-out, shear, burst detection).
  • Interactive Charts & 3D Trajectory Viewer.
  • Secure User Management (expiry, allowed_pages, force logout).
  • Optimized Gunicorn + centralized logs.

5. Architecture Overview

System

Backend: Flask modular (core/, routes/, config/), SQLite cache, Gunicorn WSGI.
Frontend: Chart.js, Leaflet, Deck.gl, DataTables dengan tema biru gradasi dan font Inter.
Deployment: Gunicorn + Nginx (systemd) atau Railway Procfile.

Conclusion

Fondasi ini mempersiapkan sistem menuju tahap berikutnya — AI-driven QC dan National Radiosonde Dashboard — untuk meningkatkan akurasi, efisiensi, dan nilai ilmiah data atmosfer nasional.
