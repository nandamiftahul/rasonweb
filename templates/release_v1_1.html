📘 Overview

Rason Monitoring (RasonWeb) adalah platform web terpadu untuk pemantauan, analisis, dan visualisasi data radiosonde berformat BUFR/BFR/BFH/BIN.

Sistem ini dikembangkan untuk menggantikan proses manual dalam validasi dan analisis data hasil peluncuran balon udara, menggunakan teknologi modern berbasis web yang cepat, modular, dan interaktif.

Refactor Release (v1.1.0) menandai selesainya fase utama pengembangan sistem dengan struktur backend yang terpisah, frontend seragam, dan fitur analitik lengkap.

🎯 Project Objective

  • Menstandarkan proses decoding dan QC radiosonde di seluruh stasiun.
  • Menyediakan analisis otomatis berbasis fisika atmosfer.
  • Menampilkan hasil secara visual dan interaktif melalui dashboard web.
  • Memungkinkan monitoring performa dan kualitas data antar site secara real-time.
  • Menyediakan manajemen user dan keamanan terintegrasi.

🏗️ System Architecture

Backend Layer

  • Flask Framework dengan struktur modular
  • Package: core/, routes/, config/
  • SQLite sebagai cache metadata
  • Gunicorn sebagai WSGI server

Frontend Layer

  • Chart.js v4, DataTables, Leaflet, Deck.gl
  • Sidebar collapsible, tema biru gradasi, font Inter

Deployment Layer

  • Gunicorn + Nginx via systemd service
  • Railway/Render dengan Procfile
  • Centralized log dan upload folder terpisah

🧩 Key Features

  1. Automatic Data Decoding – BUFR/BFR/BFH/BIN support, auto cache ke SQLite, FTP fallback
  2. Deep Physics Analysis – Cold point, RH freeze-out, lapse rate inversion, burst detection, wind shear, RH–T mismatch
  3. Interactive Visualization – 4 grafik Chart.js, Data Availability Calendar, Height Reach Graph, 3D Trajectory, Time Accuracy
  4. User & Access Management – Hash password, expiry, single session, allowed pages, force logout
  5. Performance & Security – Optimized Gunicorn, centralized logs, offline static libs, clear 403 UI

📡 Available API Endpoints

Semua endpoint menggunakan @login_required dan role-based access.

User Management

  • /api/users – CRUD user
  • /admin/logout_all – Logout semua user
  • /admin/active_users – Daftar user aktif

Data Analysis

  • /api/time_accuracy/<site> – Analisis AA–DD
  • /api/height_reach/<site> – Tinggi maksimum
  • /api/data_availability – Status harian
  • /raob/<site>/<file> – Analisis RAOB
