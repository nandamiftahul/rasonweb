RASON Monitoring — Development Roadmap

Perencanaan versi lanjutan hingga Data Intelligence Hub (2026)

Version: v1.2 → v2.0 Updated: 28 October 2025 Prepared by: Terrindo

1. Ikhtisar Proyek

Overview

RASON Monitoring adalah platform web untuk analisis data radiosonde BMKG. Setelah refactor (v1.1.0), fokus pengembangan berikutnya adalah memperluas sistem menjadi Data Intelligence Platform yang mencakup AI QC, laporan otomatis, dashboard nasional, dan integrasi model numerik.

3. Fase 1.2 — Smart QC & Reports

AI & QC
  • AI-assisted QC: Model ML untuk klasifikasi sounding (Normal / Error / Burst / Freeze-out).
  • Anomaly Detection: Deteksi otomatis sounding ekstrem (wind shear, lapse rate abnormal).
  • Monthly Report: Laporan PDF otomatis (height, success rate, sensor trend).
  • Notifications: Email/Telegram alert untuk site inaktif & error berulang.
  • Database upgrade: Migrasi ke PostgreSQL untuk data historis.

4. Fase 1.3 — National Dashboard

Integrasi Multi-Site
  • National Map Overview: Peta seluruh site radiosonde Indonesia (status OK/Warn/Offline).
  • Cross-Site Comparison: Grafik burst rate & height per site per bulan.
  • Real-time Launch Monitor: Status inflight / standby via file log FTP.
  • Central Admin Panel: Manajemen seluruh site dari satu halaman.
  • Central Cache DB: Hasil QC tersimpan di basis data nasional.

5. Fase 2.0 — Data Intelligence Hub

Integrasi AI & NWP
  • Data Assimilation: Ekspor hasil decode ke format NetCDF untuk WRF/ICON.
  • AI Nowcasting: Analisis radiosonde + satelit untuk prediksi konveksi.
  • Climate Trend Analysis: Analisis tren tropopause, lapse rate, RH musiman.
  • Data Sharing API: API publik untuk integrasi WebGIS / riset.
  • Data Lake Integration: Penyimpanan file jangka panjang (S3/MinIO).

6. Inovasi Mendatang

Future Ideas
  • Prediksi burst altitude berbasis kondisi awal (AI Flight Predictor).
  • Analisis performa per batch sensor atau balon (Calibration Analyzer).
  • Versi mobile (PWA) untuk monitoring lapangan.
  • Integrasi citra Himawari dan radar.
  • Portal dataset radiosonde publik untuk riset atmosfer.

7. Kesimpulan

Summary

Rason Monitoring berkembang dari sistem QC internal menjadi platform analisis atmosfer nasional. Versi 1.2–2.0 akan memperkenalkan QC berbasis AI, laporan otomatis, dashboard nasional, dan integrasi model numerik. Tujuan akhirnya adalah menciptakan National Radiosonde Data Intelligence Hub yang mendukung operasi, riset, dan prediksi atmosfer modern BMKG.
