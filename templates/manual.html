✅ QUICK START — ALUR CEPAT (3 MENIT)

Bagian ini dibuat untuk operator yang ingin langsung menggunakan aplikasi tanpa membaca seluruh detail modul.

Quick Tujuan: Login → pilih modul → filter data → lihat hasil → export (bila perlu).

🚀 Langkah Cepat

  1. Login → buka halaman login, isi Username & Password, lalu klik Login.
  2. Masuk Main Page → cek status site di peta (Online/Offline/Inflight/Preparing).
  3. Pilih modul di sidebar (contoh: Data Resume, Map View, Time Accuracy).
  4. Set filter → pilih Site, Date/Month/Year, Hour, dan File Type sesuai kebutuhan.
  5. Klik tombol aksi (misal Apply, Load Data, atau List Files) → tunggu data tampil.
  6. Analisis & Export → gunakan tabel/grafik; export CSV jika tersedia di modul.

🧭 Navigasi Dasar yang Selalu Sama

  • Sidebar di kiri: daftar modul utama.
  • Toggle Sidebar (☰ / ❮): sembunyikan/tampilkan sidebar (tersimpan di localStorage).
  • Ikon User (👤): info akun + logout.
  • Header Box: judul modul + jam UTC.

🔑 LOGIN — LANGKAH OPERASI

🧾 Step-by-step

  1. Buka halaman login aplikasi.
  2. Klik kolom Username → ketik username.
  3. Klik kolom Password → ketik password.
  4. Klik tombol Login .
  5. Jika sukses, sistem otomatis pindah ke Main Page (/main).
Jika gagal
  • Muncul pesan error (kredensial salah / akun expired).
  • Pastikan caps lock tidak aktif dan koneksi server normal.

✅ Output yang benar

  • Anda melihat peta Indonesia + sidebar menu utama.
  • Jam UTC di header berjalan (update per detik).

🏠 MAIN PAGE — OPERASI HARIAN

🧾 Step-by-step (cek status site)

  1. Lihat peta Indonesia → perhatikan warna marker:
    • 🟢 Online
    • 🟠 Preparing
    • 🔵 Inflight
    • 🔴 Offline
  2. Arahkan mouse ke marker site → baca tooltip (nama site, status, last update).
  3. Lihat Status Grid → cek ringkasan launch/end, end pressure, max height, termination.
  4. Jika ingin analisis detail, klik menu modul di sidebar.
Navigasi
  • Klik ☰ / ❮ untuk hide/show sidebar.
  • Klik 👤 untuk info akun + logout cepat.

📊 DATA RESUME (DASHBOARD) — FILTER & EXPORT

🧾 Step-by-step (ambil daftar file & metadata)

  1. Klik menu Data Resume di sidebar.
  2. Di panel filter, pilih File Type (misal .bfr / .bufr / .bfh / .bin).
  3. Pilih Start Date dan End Date.
  4. Klik Apply → sistem memuat tabel daftar file.
  5. Jika ingin metadata lengkap, klik Show Metadata (jika tombol tersedia).
  6. Jika ingin export, klik Generate CSV → unduh hasil CSV.
Tips
  • Gunakan rentang tanggal kecil dulu untuk loading cepat.
  • Status warna tabel: OK (hijau), Warning (oranye), Issues (merah).

✅ Output yang benar

  • Tabel terisi dengan file per site + metadata utama.
  • Ikon aksi (buka/unduh/analisis) tampil sesuai implementasi sistem Anda.

🗺️ MAP VIEWER — PUTAR LINTASAN (PLAYBACK)

🧾 Step-by-step (load data dari server)

  1. Klik menu Map View di sidebar.
  2. Pilih Site.
  3. Pilih Date → lalu pilih Hour (00Z/12Z).
  4. Pilih Type (BUFR/BFR/BFH/BIN).
  5. Klik Apply → sistem mengambil file dari server dan menampilkan lintasan di peta.
  6. Gunakan kontrol playback:
    • ⏮ mundur frame
    • ▶ / ⏸ play/pause
    • ⏭ maju frame
    • Slider untuk lompat ke frame tertentu
  7. (Opsional) Klik Show Charts untuk menampilkan grafik profil (angin/suhu/dewpoint) bila tersedia.

📤 Step-by-step (upload file lokal)

  1. Di bagian uploader, klik Choose File / Select File.
  2. Pilih file radiosonde dari komputer (BUFR/BFR/BFH/BIN).
  3. Klik Upload (atau tombol upload yang tersedia).
  4. Tunggu status: Uploading → Decoding → Success.
  5. Jika sukses, lintasan tampil di peta + panel data terisi.
Layer
  • Ganti basemap (Esri/OSM/Hybrid) via kontrol layer bila tersedia.
  • Overlay Himawari IR (GIBS WMS) tampil sesuai konfigurasi sistem.

🌐 TRAJECTORY 3D — VISUALISASI 3 DIMENSI

🧾 Step-by-step (load data 3D)

  1. Klik menu Trajectory 3D di sidebar.
  2. Pilih Site, Date, Hour, dan Type.
  3. Klik Apply → peta 3D memuat lintasan.
  4. Gunakan ▶ / ⏸ di playback bar untuk memutar/menghentikan animasi.
  5. Atur Speed untuk mempercepat/perlambat.
  6. Geser Progress Slider untuk lompat ke waktu/ketinggian tertentu.
Analisis Layer
  • Aktifkan Wind Shear (ikon angin) bila tersedia.
  • Aktifkan Freezing Level (ikon ❄️) bila tersedia.
  • Perhatikan panel level (kanan atas) untuk nilai numerik tiap lapisan.

⏱️ TIME ACCURACY — OPERASI MONITORING WAKTU

🧾 Step-by-step (tampilkan grafik & tabel)

  1. Klik menu Time Accuracy di sidebar.
  2. Pilih Site.
  3. Pilih Month dan Year.
  4. Pilih Launch Time (00Z / 12Z / All).
  5. Halaman akan memuat grafik & tabel sesuai filter (secara otomatis atau via tombol load, tergantung implementasi).
  6. Arahkan mouse ke bar chart → lihat tooltip durasi setiap fase (Prep→Launch, Launch→AB, AB→Burst).
  7. Scroll ke tabel → cek kolom Date, Launch, AB, Burst.
Interpretasi cepat
  • Bar makin tinggi = durasi makin lama.
  • Perbandingan 00Z vs 12Z memudahkan deteksi keterlambatan pola operasional.

🎈 HEIGHT REACH — OPERASI PEMANTAUAN KETINGGIAN

🧾 Step-by-step (tampilkan grafik height & pressure)

  1. Klik menu Height Reach di sidebar.
  2. Pilih Site.
  3. Pilih Month dan Year.
  4. Pilih Launch Time (00Z / 12Z / All).
  5. Tunggu grafik muncul (line chart) + tabel bawah.
  6. Arahkan mouse ke titik grafik → baca nilai Height.
  7. Scroll ke tabel → cek kolom Date, Height, Pressure.
Indikasi anomali
  • Height rendah mendadak di satu hari → potensi burst dini / masalah gas/balloon.
  • Pressure akhir tinggi (mis. > 100 hPa) → indikator flight berhenti terlalu cepat.

📅 DATA AVAILABILITY — OPERASI CEK KELENGKAPAN DATA

🧾 Step-by-step (load tabel kalender)

  1. Klik menu Data Availability di sidebar.
  2. Pilih Month dan Year.
  3. Pilih Jam (00Z / 12Z) bila ada selector jam.
  4. Klik Load Data (atau auto-load sesuai implementasi).
  5. Scroll horizontal untuk melihat tanggal 1–31.
  6. Arahkan mouse ke simbol lingkaran → baca tooltip (complete/partial/no data).
Arti warna umum
  • Hijau = data lengkap
  • Kuning = data sebagian / tidak lengkap
  • Merah = tidak ada data

⚠️ ERROR ANALYSIS — OPERASI QC & DIAGNOSTIK

🧾 Step-by-step (analisis satu flight)

  1. Klik menu Error Analysis di sidebar.
  2. Pilih Site.
  3. Pilih Date.
  4. Pilih Hour (00Z / 12Z).
  5. Pilih File Type (BUFR / BFR / BFH / BIN).
  6. Klik 📁 List Files untuk memunculkan daftar file yang tersedia.
  7. Pilih file yang ingin dianalisis.
  8. Sistem menampilkan:
    • 4 grafik (Temp, RH, Wind Speed, Wind Direction)
    • Tabel level data (Pressure/Height/Temp/Dewpoint/RH/Wind)
    • Hasil Deep Physics (issues + atmospheric features)
Checklist operator
  • Grafik tidak kosong (terutama RH & Dewpoint bila mapping benar).
  • Tabel level terisi (minimal pressure/height/temp/wind).
  • Bagian “Potential Operational Issues” memberi indikasi bila ada anomali.
Jika grafik/tabel kosong
  • Coba ganti File Type (mis. BFR vs BUFR) dan ulangi list files.
  • Pastikan mapping BUFR sesuai (cek di Settings → BUFR Mapping).
  • Pastikan file berhasil ter-decode (tidak error di backend).

⚙️ SETTINGS — OPERASI ADMIN (USER & CONFIG)

Admin Only Catatan: Menu ini umumnya hanya bisa diakses akun admin. User biasa biasanya hanya melihat tab tertentu (mis. Serial Lookup).

👥 Step-by-step — User Management

  1. Klik menu Settings di sidebar.
  2. Buka tab User Management.
  3. Untuk edit user:
    • Klik ikon ✏️ pada user → ubah field (password/expiry/pages) sesuai kebutuhan.
    • Klik Save / Update (sesuai tombol di UI).
  4. Untuk hapus user, klik 🗑️ lalu konfirmasi.
  5. Untuk force logout user, gunakan tombol Logout / Force logout (jika tersedia).

🌐 Step-by-step — Site Configuration

  1. Buka tab Site Configuration.
  2. Untuk tambah site: klik ➕ Add Site → isi nama, lat, lon, offset → Save.
  3. Untuk edit site: klik ✏️ → ubah koordinat → Save.
  4. Untuk hapus site: klik 🗑️ → konfirmasi.

🧩 Step-by-step — BUFR Mapping Configuration

  1. Buka tab BUFR Mapping.
  2. Pilih scope mapping (global/per-site) bila tersedia.
  3. Tambah field: klik ➕ → isi descriptor/name/type → Save.
  4. Edit field: klik ✏️ → ubah mapping → Save.
  5. Export/Import JSON: gunakan tombol Export / Import untuk sinkronisasi antar environment.

🔍 Step-by-step — Serial Lookup

  1. Buka tab Serial Lookup.
  2. Ketik nomor seri (contoh: 230451).
  3. Klik Search → detail serial tampil.

🗂️ Step-by-step — FTP vs Database

  1. Buka tab FTP vs Database.
  2. Pilih Site, File Type, Start, End.
  3. Klik Refresh untuk menampilkan daftar file FTP & DB.
  4. Jika ingin sinkron:
    • Klik Insert FTP → DB (jika tersedia).
    • Atau Re-download untuk refresh file dari FTP.

🧰 TROUBLESHOOT — MASALAH UMUM & SOLUSI CEPAT

Cepat Jika terjadi error, fokus ke 3 hal: Filter benar → File tersedia → Decode sukses.

1) Data tidak muncul setelah Apply/Load

  • Periksa pilihan Site/Date/Hour/Type (salah jam/tipe adalah kasus paling sering).
  • Klik List Files (jika ada) untuk memastikan file benar-benar tersedia.
  • Coba periode/tanggal lain untuk memastikan server ada data.

2) Grafik kosong tapi tabel ada (atau sebaliknya)

  • Indikasi mismatch mapping variable (cek Settings → BUFR Mapping).
  • Coba format file lain (BUFR vs BFR).
  • Refresh halaman (hard refresh) untuk cache JS yang nyangkut.

3) Halaman terasa lambat

  • Perkecil rentang tanggal.
  • Hindari membuka banyak tab browser sekaligus.
  • Pastikan koneksi ke server stabil.

4) Tidak bisa akses Settings

  • Akun Anda bukan role admin, atau halaman access belum diaktifkan.
  • Hubungi admin untuk menambahkan akses pada menu terkait.
