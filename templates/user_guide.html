RASON Monitoring — User Guide

Panduan Penggunaan Sistem Radiosonde Monitoring v1.1.0

Version: v1.1.0 Release: 28 Oct 2025 Developed by: Terrindo · BMKG

1. Overview

Introduction

Rason Monitoring adalah sistem web untuk analisis data radiosonde BMKG. Sistem ini melakukan decoding otomatis file BUFR/BFR/BFH/BIN, menampilkannya dalam grafik, tabel, dan peta interaktif. Akses pengguna dibagi menjadi Admin dan User biasa dengan masa aktif (expiry) dan batas akses halaman tertentu.

2. Login Page

Authentication
  • URL: /login
  • Masukkan username dan password yang diberikan admin.
  • Jika akun sudah kadaluarsa, muncul pesan merah “Subscription expired”.
  • Setelah login, sistem membuat token unik dan menandai user sebagai aktif.
  • Login baru akan otomatis menggantikan sesi lama (single session enforcement).

3. Main Page

Dashboard

Halaman utama dengan tampilan navigasi sidebar, header box, dan footer.

  • Sidebar: navigasi ke semua fitur (Data Availability, Time Accuracy, dsb).
  • Header Box: judul halaman + jam digital real-time.
  • Footer: “Powered by Terrindo”.
  • Sidebar dapat di-collapse dan posisi terakhir disimpan oleh localStorage.

4. Fitur Utama

Pages
  • Dashboard (/dashboard) — Menampilkan daftar file radiosonde dari FTP berdasarkan ekstensi dan jumlah limit.
  • Time Accuracy (/time_accuracy) — Grafik deviasi waktu AA–DD vs jam peluncuran (00Z/12Z).
  • Height Reach (/height_reach) — Grafik ketinggian maksimum tiap peluncuran.
  • Data Availability (/data_availability) — Kalender ketersediaan data per hari/site (warna merah, kuning, hijau).
  • Error Analysis (/error_analysis) — 4 grafik QC (T, RH, WS, WD vs Height) + hasil deepPhysics().
  • Trajectory 3D (/trajectory3d) — Visual lintasan radiosonde dalam 3D (Deck.gl + MapLibre).
  • RAOB Analysis (/analysis / /raob) — Diagram Skew-T dan Hodograph, indeks CAPE/CIN/LCL, SRH, Tropopause.
  • Map View (/map) — Peta posisi radiosonde 2D (Leaflet).
  • Settings (/settings) — Tab User Management & BUFR Mapping Configuration (khusus admin).
  • Release Page (/release) — Catatan rilis & pembaruan versi.
  • Under Development (/underdev) — Placeholder fitur mendatang.

5. Admin Features

Administration
  • Tambah / hapus user melalui Settings tab.
  • Atur expiry date dan daftar halaman yang dapat diakses.
  • Lihat daftar user aktif (/admin/active_users).
  • Force logout user tertentu (/admin/logout_user/<username>).
  • Logout seluruh user sekaligus (/admin/logout_all).

6. Logout

Session End

Logout melalui menu atau URL /logout akan menghapus session dan cookie pengguna, menghapus user dari daftar aktif, lalu mengarahkan kembali ke halaman login.

7. Ringkasan

Summary

RASON Monitoring v1.1.0 menyediakan sistem analisis radiosonde lengkap — dari decoding, QC, hingga visualisasi 3D — dengan desain antarmuka profesional dan keamanan berbasis token. Platform ini mendukung operasional nasional BMKG serta siap dikembangkan menjadi sistem intelijen atmosfer modern.
